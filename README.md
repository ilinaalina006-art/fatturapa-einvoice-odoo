# FatturaPA E-Invoice Import & Validation (Odoo)

An Odoo module that imports Italian electronic invoices (FatturaPA / SDI XML format),
parses them, and automatically validates them — flagging VAT issues, missing IBANs,
credit/debit notes, incomplete supplier records, and costs that may need to be
deferred across periods — before a vendor bill is created.

Built as part of a small team effort during a client engagement. This version has
been cleaned of all client-identifying information (names, company data, internal
references) before being shared publicly — the logic and structure are unchanged,
only the sensitive parts have been removed or genericized.
